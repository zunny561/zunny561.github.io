📦 Variabel dalam Python

Apa itu Variabel?

Variabel adalah tempat untuk menyimpan data dalam program. Bayangkan variabel seperti kotak yang diberi label untuk menyimpan berbagai jenis barang.

💡 Konsep Dasar Variabel

Membuat Variabel:
# Membuat variabel
nama = "Budi"
umur = 17
tinggi = 165.5
Aturan Penamaan:
  • • Dimulai dengan huruf atau underscore (_)
  • • Tidak boleh dimulai dengan angka
  • • Tidak boleh menggunakan spasi
  • • Case sensitive (nama ≠ Nama)
  • • Tidak boleh menggunakan keyword Python

🏷️ Tipe Data dalam Python

Jenis-jenis Tipe Data

Python memiliki berbagai tipe data untuk menyimpan berbagai jenis informasi. Setiap tipe data memiliki karakteristik dan kegunaan yang berbeda.

🔢 Integer (int)

Bilangan bulat positif atau negatif

umur = 17
suhu = -5
tahun = 2024

🔢 Float

Bilangan desimal

tinggi = 165.5
pi = 3.14159
harga = 25000.0

📝 String (str)

Teks atau karakter

nama = "Siti"
alamat = 'Jakarta'
pesan = """Hello World"""

✅ Boolean (bool)

Nilai True atau False

lulus = True
hadir = False
aktif = True

📋 List

Kumpulan data yang berurutan

nilai = [85, 90, 78]
nama = ["Ali", "Budi"]
campuran = [1, "text", True]

📖 Dictionary (dict)

Data dengan pasangan key-value

siswa = {
  "nama": "Ana",
  "umur": 17
}

🤔 Percabangan (IF Statement)

Apa itu Percabangan?

Percabangan memungkinkan program membuat keputusan berdasarkan kondisi tertentu. Seperti kehidupan sehari-hari, program dapat memilih jalur yang berbeda tergantung situasi.

🏗️ Struktur Percabangan

IF Sederhana:
if kondisi:
    # kode jika True
    print("Kondisi benar")
IF-ELSE:
if kondisi:
    # jika True
else:
    # jika False
IF-ELIF-ELSE:
if kondisi1:
    # pilihan 1
elif kondisi2:
    # pilihan 2
else:
    # pilihan default

🎯 Nested IF (Percabangan Bersarang)

Contoh Nested IF:
umur = 17
nilai = 85

if umur >= 17:
    if nilai >= 80:
        print("Bisa ikut olimpiade!")
    else:
        print("Perlu belajar lebih giat")
else:
    print("Belum cukup umur")
Alternatif dengan AND:
umur = 17
nilai = 85

if umur >= 17 and nilai >= 80:
    print("Bisa ikut olimpiade!")
elif umur >= 17:
    print("Perlu belajar lebih giat")
else:
    print("Belum cukup umur")

📚 Jenis-jenis Function

Function dengan Return
def tambah(a, b):
    return a + b

hasil = tambah(5, 3)
print(hasil) # Output: 8

Function yang mengembalikan nilai

Function tanpa Return
def tampilkan_info(nama, umur):
    print(f"Nama: {nama}")
    print(f"Umur: {umur}")

tampilkan_info("Ali", 17)

Function yang hanya menjalankan aksi

🎯 Parameter dan Argument

Parameter Default:
def sapa(nama, sapaan="Halo"):
    return f"{sapaan}, {nama}!"

print(sapa("Budi"))
print(sapa("Ana", "Hi"))
Multiple Parameters:
def hitung_rata(*angka):
    return sum(angka) / len(angka)

rata = hitung_rata(80, 85, 90)
print(rata)
Keyword Arguments:
def profil(**info):
    for key, value in info.items():
        print(f"{key}: {value}")

profil(nama="Siti", umur=16)

🔄 Perulangan dalam Python

Mengapa Perlu Perulangan?

Perulangan memungkinkan kita menjalankan kode yang sama berulang kali tanpa menulis ulang. Sangat berguna untuk memproses data dalam jumlah besar atau melakukan tugas berulang.

🔄 For Loop

Digunakan ketika kita tahu berapa kali perulangan akan dilakukan

for i in range(5):
    print(f"Perulangan ke-{i}")

🔄 While Loop

Digunakan ketika perulangan bergantung pada kondisi tertentu

i = 0
while i < 5:
    print(f"Nilai i: {i}")
    i += 1

🎯 Kontrol Perulangan

Break

Menghentikan perulangan

for i in range(10):
    if i == 5:
        break
    print(i)
Continue

Melanjutkan ke iterasi berikutnya

for i in range(5):
    if i == 2:
        continue
    print(i)
Else

Dijalankan jika loop selesai normal

for i in range(3):
    print(i)
else:
    print("Selesai!")

🔢 Nested Loop (Perulangan Bersarang)

Contoh Nested Loop:
# Membuat pola bintang
for baris in range(5):
    for kolom in range(baris + 1):
        print("*", end="")
    print() # Pindah baris
Output:
*
**
***
****
*****
