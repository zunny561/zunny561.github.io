Definisi Jaringan Komputer

Jaringan komputer adalah kumpulan dua atau lebih komputer yang saling terhubung untuk berbagi sumber daya, data, dan informasi. Jaringan memungkinkan komunikasi dan kolaborasi antar pengguna di lokasi yang berbeda.

🔗 Konektivitas

Menghubungkan perangkat untuk komunikasi

📊 Berbagi Sumber Daya

Sharing file, printer, dan aplikasi

⚡ Efisiensi

Meningkatkan produktivitas kerja

🔗 Topologi Jaringan

Topologi jaringan adalah cara atau pola yang digunakan untuk menghubungkan komputer-komputer dalam suatu jaringan. Pemilihan topologi yang tepat sangat penting untuk kinerja dan keandalan jaringan.

🚌 Topologi Bus

Kelebihan: Mudah dipasang, biaya rendah

Kekurangan: Jika kabel utama rusak, seluruh jaringan down

Penggunaan: Jaringan kecil, kantor sederhana

⭐ Topologi Star

Kelebihan: Mudah troubleshooting, kerusakan satu node tidak mempengaruhi yang lain

Kekurangan: Bergantung pada hub/switch pusat

Penggunaan: Jaringan kantor modern, sekolah

💍 Topologi Ring

Kelebihan: Tidak ada collision, performa konsisten

Kekurangan: Jika satu node rusak, seluruh jaringan terganggu

Penggunaan: Jaringan fiber optic, FDDI

🕸️ Topologi Mesh

Kelebihan: Redundansi tinggi, sangat reliable

Kekurangan: Biaya tinggi, kompleks

Penggunaan: Jaringan kritis, internet backbone

💡 Tips Memilih Topologi

Pertimbangan Teknis:

  • • Jumlah komputer yang akan dihubungkan
  • • Jarak antar komputer
  • • Kebutuhan bandwidth
  • • Tingkat keamanan yang diperlukan

Pertimbangan Ekonomis:

  • • Budget yang tersedia
  • • Biaya maintenance
  • • Kemudahan troubleshooting
  • • Skalabilitas untuk masa depan

⚙️ Konfigurasi Jaringan

Konfigurasi jaringan adalah proses pengaturan parameter-parameter jaringan agar komputer dapat berkomunikasi dengan benar dalam suatu jaringan.

🏠 Alamat IP (IP Address)

IPv4

192.168.1.100

Format: xxx.xxx.xxx.xxx (0-255)

Kelas A: 1.0.0.0 - 126.255.255.255

Kelas B: 128.0.0.0 - 191.255.255.255

Kelas C: 192.0.0.0 - 223.255.255.255

Subnet Mask

255.255.255.0

Menentukan bagian network dan host

/24: 255.255.255.0 (254 host)

/16: 255.255.0.0 (65,534 host)

/8: 255.0.0.0 (16,777,214 host)

🔄 DHCP vs Static IP

🔄 DHCP (Dynamic)

IP address diberikan secara otomatis oleh DHCP server

Kelebihan:
  • • Mudah dikelola
  • • Tidak ada konflik IP
  • • Otomatis konfigurasi
Kekurangan:
  • • IP dapat berubah
  • • Bergantung pada DHCP server

📌 Static IP

IP address dikonfigurasi manual dan tetap

Kelebihan:
  • • IP tidak berubah
  • • Cocok untuk server
  • • Kontrol penuh
Kekurangan:
  • • Konfigurasi manual
  • • Risiko konflik IP

📋 Langkah Konfigurasi Dasar

Windows:

  1. 1. Buka Control Panel → Network and Internet
  2. 2. Pilih Network and Sharing Center
  3. 3. Klik "Change adapter settings"
  4. 4. Klik kanan pada koneksi → Properties
  5. 5. Pilih "Internet Protocol Version 4 (TCP/IPv4)"
  6. 6. Masukkan IP, Subnet Mask, Gateway, DNS

Parameter Penting:

IP Address: Alamat unik komputer
Subnet Mask: Membagi network dan host
Default Gateway: Pintu keluar ke jaringan lain
DNS Server: Menerjemahkan nama domain

🤝 Jaringan Peer-to-Peer (P2P)

Peer-to-Peer (P2P) adalah model jaringan di mana setiap komputer dapat berfungsi sebagai client dan server secara bersamaan. Tidak ada server pusat yang mengontrol jaringan.

⚖️ P2P vs Client-Server

🤝 Peer-to-Peer

Karakteristik:
  • • Tidak ada server pusat
  • • Setiap node adalah client dan server
  • • Berbagi sumber daya langsung

🏢 Client-Server

Karakteristik:
  • • Ada server pusat
  • • Client meminta layanan ke server
  • • Kontrol terpusat

💻 Contoh Penerapan P2P

🎵 File Sharing

Contoh: BitTorrent, eMule

Cara Kerja: File dibagi menjadi potongan kecil dan didistribusikan ke banyak peer

Keuntungan: Download lebih cepat, tidak bergantung pada satu server

💰 Cryptocurrency

Contoh: Bitcoin, Ethereum

Cara Kerja: Blockchain tersebar di seluruh jaringan peer

Keuntungan: Desentralisasi, transparansi, keamanan

💬 Komunikasi

Contoh: Skype (versi lama), Discord P2P

Cara Kerja: Komunikasi langsung antar pengguna

Keuntungan: Latensi rendah, privasi lebih baik

🎮 Gaming

Contoh: Multiplayer games, LAN gaming

Cara Kerja: Player terhubung langsung untuk bermain

Keuntungan: Latensi rendah, tidak perlu server game

☁️ Distributed Storage

Contoh: IPFS, Storj

Cara Kerja: File disimpan tersebar di banyak node

Keuntungan: Redundansi, ketahanan terhadap kegagalan

🌐 Content Delivery

Contoh: WebRTC, P2P CDN

Cara Kerja: Konten didistribusikan melalui peer terdekat

Keuntungan: Bandwidth efisien, skalabilitas

⚖️ Kelebihan dan Kekurangan P2P

✅ Kelebihan

💰
Biaya Rendah

Tidak perlu server khusus yang mahal

🔄
Skalabilitas

Performa meningkat seiring bertambahnya peer

🛡️
Fault Tolerance

Tidak ada single point of failure

🚀
Performa

Bandwidth terdistribusi, download lebih cepat

❌ Kekurangan

🔒
Keamanan

Sulit mengontrol akses dan keamanan data

⚙️
Manajemen

Sulit mengelola dan memantau jaringan

📊
Konsistensi Data

Sulit menjaga konsistensi data di semua peer

⚖️
Legal

Potensi masalah hukum terkait konten ilegal

🛠️ Implementasi P2P Sederhana

Langkah-langkah:

  1. 1. Discovery: Peer mencari peer lain dalam jaringan
  2. 2. Connection: Membuat koneksi langsung antar peer
  3. 3. Authentication: Verifikasi identitas peer
  4. 4. Data Exchange: Pertukaran data atau layanan
  5. 5. Maintenance: Menjaga koneksi dan sinkronisasi

Teknologi Pendukung:

DHT (Distributed Hash Table): Untuk pencarian peer
NAT Traversal: Mengatasi firewall dan NAT
Encryption: Mengamankan komunikasi
Consensus Algorithm: Untuk sinkronisasi data

📝 Evaluasi Pembelajaran

Uji pemahaman Anda tentang materi Jaringan Komputer dan Internet yang telah dipelajari.

1. Topologi jaringan yang menggunakan kabel utama (backbone) sebagai media transmisi adalah:

Penjelasan: Topologi Bus menggunakan satu kabel utama (backbone) yang menghubungkan semua komputer dalam jaringan. Semua data yang dikirim akan melewati kabel utama ini.

2. Dalam konfigurasi jaringan, fungsi dari Subnet Mask adalah:

Penjelasan: Subnet Mask berfungsi untuk membagi alamat IP menjadi dua bagian: bagian network (jaringan) dan bagian host (komputer). Ini membantu router menentukan apakah alamat tujuan berada dalam jaringan lokal atau jaringan lain.

3. Karakteristik utama dari jaringan Peer-to-Peer (P2P) adalah:

Penjelasan: Dalam jaringan P2P, tidak ada pembedaan antara client dan server. Setiap komputer (peer) dapat memberikan layanan kepada peer lain sekaligus meminta layanan dari peer lain. Ini berbeda dengan model client-server yang memiliki pembagian peran yang jelas.

4. Contoh penerapan teknologi P2P dalam kehidupan sehari-hari adalah:

Penjelasan: BitTorrent adalah protokol P2P untuk file sharing, sedangkan cryptocurrency seperti Bitcoin menggunakan jaringan P2P untuk blockchain. Keduanya tidak bergantung pada server pusat dan menggunakan prinsip peer-to-peer.

5. Kelebihan utama dari topologi Star dibandingkan topologi Bus adalah:

Penjelasan: Dalam topologi Star, setiap komputer terhubung langsung ke hub/switch pusat. Jika satu komputer rusak, hanya komputer tersebut yang terputus dari jaringan, sedangkan komputer lain tetap dapat berkomunikasi. Berbeda dengan topologi Bus yang jika kabel utama rusak, seluruh jaringan akan down.
