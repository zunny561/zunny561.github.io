💻 Single Board Computer (SBC)

Apa itu Single Board Computer?

Single Board Computer adalah komputer lengkap yang dibangun dalam satu papan sirkuit. Berbeda dengan komputer desktop yang komponennya terpisah, SBC mengintegrasikan CPU, RAM, storage, dan I/O dalam satu board.

🏗️ Karakteristik SBC

Komponen Terintegrasi:
  • • CPU (Central Processing Unit)
  • • RAM (Random Access Memory)
  • • Storage (eMMC/microSD)
  • • GPU (Graphics Processing Unit)
  • • I/O Ports (USB, HDMI, GPIO)
Keunggulan SBC:
  • • Ukuran kompak dan portabel
  • • Konsumsi daya rendah
  • • Harga terjangkau
  • • Mudah diintegrasikan
  • • Cocok untuk embedded system

🔍 Jenis-jenis Single Board Computer

🍓
Raspberry Pi
  • • ARM Cortex processor
  • • Linux-based OS
  • • GPIO pins untuk I/O
  • • HDMI, USB, Ethernet
  • • Cocok untuk pembelajaran
🔧
Arduino
  • • Microcontroller-based
  • • Real-time processing
  • • Analog & digital I/O
  • • Simple programming
  • • Ideal untuk prototyping
⚡
ESP32
  • • WiFi & Bluetooth built-in
  • • Dual-core processor
  • • Low power consumption
  • • IoT applications
  • • Arduino IDE compatible

🔧 Pengenalan Arduino

Apa itu Arduino?

Arduino adalah platform prototyping elektronik open-source yang terdiri dari hardware (board) dan software (IDE). Arduino memudahkan pembuatan proyek interaktif yang dapat membaca input dari sensor dan mengontrol output seperti LED, motor, atau speaker.

🏗️ Hardware Arduino

  • •Microcontroller (ATmega328P)
  • •Digital I/O pins (0-13)
  • •Analog input pins (A0-A5)
  • •Power supply (USB/DC jack)
  • •Reset button

💻 Software Arduino

  • •Arduino IDE (Integrated Development Environment)
  • •Bahasa pemrograman C/C++
  • •Library yang lengkap
  • •Serial Monitor untuk debugging
  • •Community support

📋 Jenis-jenis Board Arduino

🔵
Arduino Uno
  • • ATmega328P microcontroller
  • • 14 digital I/O pins
  • • 6 analog input pins
  • • 32KB Flash memory
  • • Paling populer untuk pemula
🟢
Arduino Nano
  • • Ukuran kecil dan compact
  • • Fungsi sama dengan Uno
  • • Mini USB connector
  • • Breadboard friendly
  • • Cocok untuk proyek permanen
🔴
Arduino Mega
  • • ATmega2560 microcontroller
  • • 54 digital I/O pins
  • • 16 analog input pins
  • • 256KB Flash memory
  • • Untuk proyek kompleks

⚡ Komponen Arduino

Komponen Dasar Arduino

Untuk membuat proyek Arduino, kita membutuhkan berbagai komponen elektronik. Mari pelajari komponen-komponen dasar dan fungsinya.

🔌 Komponen Input

🌡️
Sensor Suhu (DHT22)
  • • Mengukur suhu dan kelembaban
  • • Range: -40°C to 80°C
  • • Akurasi: ±0.5°C
  • • Interface: Digital
  • • Voltage: 3.3V - 5V
👆
Push Button
  • • Input digital sederhana
  • • Normally Open (NO)
  • • Membutuhkan pull-up resistor
  • • Debouncing diperlukan
  • • Voltage: 3.3V - 5V
💡
LDR (Light Sensor)
  • • Light Dependent Resistor
  • • Resistansi berubah dengan cahaya
  • • Interface: Analog
  • • Membutuhkan voltage divider
  • • Range: 1MΩ (gelap) - 10kΩ (terang)

💡 Komponen Output

💡
LED
  • • Light Emitting Diode
  • • Forward voltage: ~2V
  • • Current: 20mA (max)
  • • Membutuhkan current limiting resistor
  • • Berbagai warna tersedia
🔊
Buzzer
  • • Active & Passive buzzer
  • • Active: built-in oscillator
  • • Passive: perlu PWM signal
  • • Voltage: 3V - 5V
  • • Aplikasi: alarm, notifikasi
⚙️
Servo Motor
  • • Motor dengan kontrol posisi
  • • Range: 0° - 180°
  • • Control signal: PWM
  • • 3 wire: Power, Ground, Signal
  • • Torque: varies by model

💻 Pemrograman Arduino

Struktur Program Arduino

Program Arduino (sketch) memiliki struktur dasar yang terdiri dari dua fungsi utama: setup() dan loop(). Mari pelajari struktur dan sintaks pemrograman Arduino.

🏗️ Struktur Dasar Arduino

Template Dasar:
// Deklarasi variabel global
int ledPin = 13;

void setup() {
  // Kode inisialisasi (dijalankan sekali)
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // Kode utama (dijalankan berulang)
  digitalWrite(ledPin, HIGH);
  delay(1000);
}
Penjelasan Fungsi:
  • setup(): Dijalankan sekali saat Arduino dinyalakan atau di-reset
  • loop(): Dijalankan berulang-ulang setelah setup() selesai
  • pinMode(): Mengatur pin sebagai INPUT atau OUTPUT
  • digitalWrite(): Menulis nilai HIGH atau LOW ke pin digital
  • delay(): Menunda eksekusi dalam milidetik

🌐 Simulasi dengan Wokwi

Apa itu Wokwi?

Wokwi adalah simulator Arduino online yang memungkinkan kita membuat, menguji, dan berbagi proyek Arduino tanpa memerlukan hardware fisik. Platform ini sangat berguna untuk pembelajaran dan prototyping.

🌟 Keunggulan Wokwi

Fitur Utama:
  • • Simulasi real-time yang akurat
  • • Library komponen yang lengkap
  • • Code editor dengan syntax highlighting
  • • Serial Monitor terintegrasi
  • • Sharing proyek mudah
  • • Gratis untuk penggunaan dasar
Keuntungan untuk Pembelajaran:
  • • Tidak perlu hardware fisik
  • • Eksperimen tanpa risiko kerusakan
  • • Debugging lebih mudah
  • • Akses dari mana saja
  • • Kolaborasi online
  • • Dokumentasi visual
